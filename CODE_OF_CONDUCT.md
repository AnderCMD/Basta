# Código de Conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: sé respetuoso, acepta críticas constructivas, enfócate en lo mejor para la comunidad y no toleres acoso de ningún tipo.

Los comportamientos inaceptables pueden reportarse abriendo un *issue* privado o contactando a las personas que mantienen el repositorio. Quienes mantienen el proyecto pueden eliminar comentarios, commits o contribuciones que no respeten este código.
